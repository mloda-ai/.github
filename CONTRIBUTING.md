# Contributing to mloda-ai projects

Thanks for your interest! This is the organization-wide default guide; it
applies to any mloda-ai repository that does not ship its own CONTRIBUTING.md.

## Getting started

Each repository's README documents its setup and test gate. Most Python repos
use `uv` for dependencies and `tox` as the merge gate; CI must pass before a
PR is mergeable.

## Ground rules

- **Conventional Commits.** Use `feat:` / `fix:` / `chore:` / `docs:` / etc.;
  release tooling parses them. No `Co-Authored-By` / AI-agent trailers.
